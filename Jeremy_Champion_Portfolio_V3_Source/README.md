# Jeremy Champion Portfolio — V3 Editorial / Gritty Mockup

This version keeps the V2 page structure and project order, but shifts the art direction toward a bolder, rougher editorial feel:

- Black / off-white base with restrained magenta-purple accents
- Large condensed type instead of heavy neon everywhere
- Handwritten annotations and rougher graphic details
- Existing project assets bundled locally
- Scroll reveal animations, subtle image movement and page transitions
- Responsive layout for desktop / tablet / mobile
- No build step or framework required

## Open locally
Open `index.html` directly in a browser, or use VS Code Live Server for the best local preview.

## Main files
- `index.html` — page structure and copy
- `css/styles.css` — all visual design and responsive styles
- `js/main.js` — scroll, reveal and transition interactions
- `assets/images/` — project assets
- `assets/motion/` — placeholder area for future local video files

## Easy edits
Accent colours are at the top of `css/styles.css` inside `:root`.

The Motion section currently links to the supplied Dropbox folders instead of bundling large video files.
